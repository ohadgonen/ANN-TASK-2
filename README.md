# CIFAR-10 Image Classification

This project implements and evaluates deep learning models for image classification on the CIFAR-10 dataset using PyTorch. The work includes the development, training, and analysis of both a Convolutional Neural Network (CNN) and a Multi-Layer Perceptron (MLP), followed by a comparison of their performance, computational requirements, and interpretability.

The project explores key concepts in deep learning for computer vision, including convolutional layers, activation functions, batch normalization, optimization, overfitting, model evaluation, confusion matrices, and feature visualization. Performance is assessed using standard classification metrics and visual analyses of learned representations.

The repository contains the training scripts, evaluation code, generated figures, and report materials used throughout the assignment.
